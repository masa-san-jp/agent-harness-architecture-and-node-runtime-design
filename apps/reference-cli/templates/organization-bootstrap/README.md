# Organization bootstrap scaffold

This directory was generated by the reference CLI. It is a safe, synthetic starting point for an
organization that has no harness yet. The sample inputs contain no personal data or secrets.

## Files

- `profile.json`: Profile using the built-in JSONL adapter and `input/events.jsonl`
- `policy.json`: deny-by-default bootstrap Policy; add organization-approved rules before use
- `input/events.jsonl`: synthetic sample input for the built-in adapter
- `adapter-input/events.org-export`: synthetic input for the custom adapter template
- `adapter-bundle/`: a custom adapter template, manifest, and Profile
- `.gitignore`: keeps future files placed under `input/` and `adapter-input/` out of Git by default

## First steps

1. Replace the `replace-me` identifiers in `profile.json` and choose the real classification and
   masking state.
2. Replace the sample file under `input/` with an approved local export. Keep the Profile paths
   relative to the `--input` directory.
3. Add only organization-approved Policy rules. The default is deny.
4. Validate before running the bootstrap:

```sh
pnpm --filter @agent-harness/reference-cli run cli -- \
  --validate \
  --input __SCAFFOLD_DIR__/input \
  --policy __SCAFFOLD_DIR__/policy.json \
  --profile __SCAFFOLD_DIR__/profile.json
```

5. Run the read-only reference path after validation:

```sh
pnpm --filter @agent-harness/reference-cli run cli -- \
  --input __SCAFFOLD_DIR__/input \
  --policy __SCAFFOLD_DIR__/policy.json \
  --profile __SCAFFOLD_DIR__/profile.json \
  --captured-at 2026-01-08T00:00:00Z
```

The generated `HarnessDraft` remains non-executable and the reference replay uses a fake executor.
Do not put credentials or raw production exports into the repository. Authentication and export
retrieval belong outside the importer boundary.

## Custom adapter template

To try the local adapter bundle example, use the second Profile and its `.org-export` input:

```sh
pnpm --filter @agent-harness/reference-cli run cli -- \
  --input __SCAFFOLD_DIR__/adapter-input \
  --policy __SCAFFOLD_DIR__/policy.json \
  --profile __SCAFFOLD_DIR__/adapter-bundle/profile.json \
  --adapter-bundle __SCAFFOLD_DIR__/adapter-bundle/manifest.json
```

Replace `adapter-bundle/example-adapter.mjs` with an organization-owned parser and keep its
manifest binding, read-only boundary, and tests aligned with the adapter contract.
