# Example Office observed procedure

This synthetic record describes only observations available to a bootstrap process. It is not an
approved business model and must not be treated as a complete procedure.

- A requester creates a request.
- A preparer may produce an artifact for a request.
- An approver records an approval or leaves the request pending.
- The same request type can occur more than once in a reporting period.

The records intentionally omit the complete approval policy, exception handling, and permission
scope. A candidate model must preserve those gaps as questions for human review.
